# Update CV Workflow

Use this workflow whenever a user asks ChatGPT to update, improve, correct, or tailor the CV.

## 1. Classify the request

Determine whether the request is:

- new career fact
- correction
- removal
- achievement
- project
- skill update
- wording improvement
- role-specific tailoring
- CV design/layout
- website update

## 2. Read before writing

Read the relevant:

- AgentFiles rules
- AgentFiles standards
- existing Content/Career files
- current CV/template files if the request affects presentation

## 3. Update canonical content first

Put factual changes into Content/Career before updating generated outputs.

## 4. Validate

Check:

- chronology
- duplicate information
- conflicting titles/dates
- unsupported metrics
- spelling and grammar
- technology names
- links
- consistency across CV and website

## 5. Generate/update presentation

Update the CV/site only after the canonical content is correct.

## 6. Commit

Use a focused commit message such as:

- `career: add AgCode responsibilities`
- `cv: improve backend engineering summary`
- `career: correct employment dates`
- `site: update selected projects`

## 7. Report

Tell the user exactly what changed and whether anything requires confirmation.

## ChatGPT command examples

Natural language is preferred:

- "Add my new role at X."
- "Update my CV with this project."
- "Tailor my CV for a Senior .NET role."
- "Remove Angular from my primary skills."
- "Improve the summary but don't change the facts."
- "Generate the latest CV."

Never interpret "make it better" as permission to invent achievements.
