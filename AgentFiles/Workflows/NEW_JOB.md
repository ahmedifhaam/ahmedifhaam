# New Job Workflow

1. Create or update the appropriate Content/Career/Experience entry.
2. Capture employer, title, dates, location, responsibilities, achievements, technologies, and public visibility.
3. Mark unknown fields NEEDS_CONFIRMATION.
4. Check overlap with previous employment.
5. Update the general CV only after the career entry is valid.
6. Update website content only if the role is PUBLIC.
7. Run release validation if a published CV/site is requested.
