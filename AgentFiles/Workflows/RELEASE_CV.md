# CV Release Workflow

1. Read all AgentFiles rules and standards.
2. Validate Content/Career.
3. Generate the canonical CV.
4. Run ATS and quality review.
5. Generate the PDF.
6. Verify the PDF exists and opens.
7. Update the public website's Download CV link.
8. Run site validation.
9. Commit with a release-oriented message.
10. Report the release version/date and any unresolved NEEDS_CONFIRMATION items.
