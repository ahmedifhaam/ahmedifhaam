# Privacy and Publishing Rules

## Private by default

Career source material may contain information that should not be published.

Every career item should eventually be classified as:

- PUBLIC
- PRIVATE
- NEEDS_REVIEW

## Never publish

- passwords
- API keys
- access tokens
- private credentials
- private addresses
- personal identification numbers
- confidential company information
- proprietary source code
- non-public customer information

## Contact information

Only publish email/phone details explicitly marked PUBLIC.

## Website rule

Only content marked PUBLIC may be consumed by the public website generator.
