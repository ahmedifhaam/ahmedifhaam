# Achievement Standard

Achievements should be evidence-based.

Preferred:
- action
- technical scope
- measurable result

Example:
"Reduced deployment time from X to Y by automating Z."

If no metric exists, describe the concrete outcome without inventing a number.

Avoid:
- "revolutionized"
- "world-class"
- "expert" unless independently justified
- unsupported percentages
- vague claims such as "greatly improved"
