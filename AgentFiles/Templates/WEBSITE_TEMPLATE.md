# Public CV Website Template

## Required sections

1. Hero / professional identity
2. Summary
3. Experience
4. Selected projects
5. Skills
6. Education / certifications
7. Professional links
8. Download CV

## Design

- responsive
- accessible
- fast
- minimal
- neutral background
- restrained accent colour
- strong typography
- no unnecessary animation

## Download

The site should expose a clearly labelled **Download CV** button linked to the latest published PDF.

## Data

Where practical, website content should be generated from Content/Career rather than manually duplicated.
