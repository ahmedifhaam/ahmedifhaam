# Skill: CV Tailoring

## Purpose
Create a role-specific CV variant from the canonical career profile.

## Process
1. Read the canonical career content.
2. Read the target job description supplied by the user.
3. Identify relevant requirements and terminology.
4. Emphasize matching verified experience.
5. Do not manufacture missing experience.
6. Keep dates, employers, titles, and achievements unchanged.
7. Record meaningful gaps separately rather than disguising them.

## Output
A tailored CV variant and a concise gap/coverage report.
