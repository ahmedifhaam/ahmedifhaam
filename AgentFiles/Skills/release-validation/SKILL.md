# Skill: Release Validation

Before publishing:
1. Check required career sections.
2. Check chronology.
3. Check links.
4. Check spelling and grammar.
5. Check public/private visibility.
6. Check the download artifact exists.
7. Check the Download CV action resolves.
8. Confirm no secrets or private files are included.
9. Confirm rendered content matches Content/Career.

Fail validation when a required public artifact is missing.
