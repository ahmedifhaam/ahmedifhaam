# Skill: Release Validation

Before publishing a CV or website release:

1. Check all required career sections.
2. Check chronology.
3. Check links.
4. Check spelling and grammar.
5. Check public/private visibility.
6. Check the download artifact exists.
7. Check the site has a working Download CV action.
8. Confirm no secrets or private files are included.
9. Confirm the rendered content matches Content/Career.

A release should fail validation if a required public artifact is missing.
