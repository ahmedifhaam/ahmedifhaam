# Skill: CV Writing

## Purpose
Turn verified career content into concise, evidence-based CV content.

## Rules
- Never add facts not present in Content/Career.
- Prefer action + technical context + outcome.
- Preserve technical accuracy.
- Remove repetition.
- Use terminology familiar to software engineering recruiters.
- Keep the canonical CV ATS-friendly.

## Output
A complete CV section or full CV derived from canonical content.
