# CV Outputs

This directory contains CV-related presentation artifacts.

Recommended structure:

```
CV/
├── canonical/
├── variants/
└── releases/
```

The canonical CV should represent the general professional profile. Variants may target specific role families, such as:

- Senior Software Engineer
- Backend Engineer
- .NET Engineer
- Tech Lead
- AI / Cloud Engineer

Variants must not introduce facts absent from Content/Career.
